# CareerPilot-FullStack-Automation
CareerPilot-FullStack-Automation is a full-stack automated job acquisition system designed to eliminate the friction of manual applications. By integrating Python-based scraping engines with a Java Spring Boot backend and an Angular frontend, it allows users to automate daily applications on major platforms while centralizing job descriptions and status tracking in a single, professional dashboard.

The CareerPilot Breakdown:
Bots: Python, Selenium (Automated Application & JD Scraping)

Backend: Java 17, Spring Boot, Spring Data JPA, JWT Security

Database: MySQL (Persistent storage for 5,000+ characters of JD text)

Frontend: Angular 17+, Tailwind CSS, Angular CDK (Drag-and-Drop Kanban)
